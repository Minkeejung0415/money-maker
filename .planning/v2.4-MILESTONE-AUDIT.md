## Integration Check

The route-offset layer is wired as an adapter:

1. `scripts/wc_scanner.py` loads optional projected-XI route snapshots.
2. `WCRouteOffsetEngine` evaluates coverage, duels, caps, and eligibility.
3. `WCScorelineModel` can apply route deltas to lambdas and recompute scoreline-derived WDL, BTTS, and O/U2.5.
4. Default scanner mode remains `shadow`, so production picks are not changed by route offsets.
5. `--route-offset-mode promoted` applies adjusted WDL only when route-offset eligibility passes.
6. `scripts/validate_wc_route_offsets.py` blocks promotion unless paired baseline-vs-route metrics pass.
