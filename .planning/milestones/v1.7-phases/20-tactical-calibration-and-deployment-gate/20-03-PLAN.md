# Plan 20-03: Versioned Artifact and Market-Specific Deployment Gate

## Objective

Make validated tactical residuals loadable in production without allowing absent, stale, incompatible, or failed evidence to alter baseline probabilities.

## Tasks

<task type="auto">
  <name>Task 1: Persist and validate an auditable artifact</name>
  <files>alpha/engines/sports/wc_tactical_calibration.py, scripts/train_wc_tactical_model.py, tests/unit/engines/test_wc_tactical_calibration.py</files>
  <action>Define a deterministic artifact containing schema version, feature order, weights/scalers, bounds, training cutoff, dataset fingerprint, sample counts, selected regularization, holdout metrics, bootstrap intervals, and independent 1X2/totals/BTTS gate states. Validate every field and reject unknown versions, feature mismatches, non-finite values, missing evidence, or a cutoff later than the target fixture.</action>
  <verify>Artifact round-trip and corruption tests pass; snapshots prove stable serialization and explicit rejection reasons.</verify>
  <acceptance>Runtime can determine exactly what was trained, on which data, and which markets are authorized.</acceptance>
</task>

<task type="auto">
  <name>Task 2: Integrate independent fail-closed market gates</name>
  <files>alpha/engines/sports/wc_model.py, alpha/engines/sports/wc_tactical_calibration.py, tests/unit/engines/test_wc_model.py</files>
  <action>Load the validated artifact once. Single-market screens may apply only their independently approved market output. For every SGP candidate, determine all constituent market families first and select exactly one distribution: use the tactical scoreline distribution only if the artifact's joint gate approves every constituent family on that distribution; otherwise recompute the entire combination from the no-tactics scoreline distribution. Never mix tactical and baseline marginals or joints inside one combination. Missing or rejected artifacts use no tactics, never v1.6 fixed weights. Preserve knockout rules, explanations, normalization, and caps.</action>
  <verify>Tests cover every pass/fail combination, missing/corrupt/stale artifacts, reversed teams, knockout fixtures, and exact probability sums.</verify>
  <acceptance>A failed single market is bit-for-bit equal to baseline, and every SGP joint is derived wholly from either the approved tactical distribution or the baseline distribution.</acceptance>
</task>

<task type="auto">
  <name>Task 3: Expose evidence and complete regression verification</name>
  <files>scripts/wc_scanner.py, tests/unit/scripts/test_wc_scanner.py</files>
  <action>Print artifact version/cutoff and a concise pass, fail, or fallback status for 1X2, totals, and BTTS. Continue showing baseline versus adjusted percentages only for active markets and include the gate reason for inactive ones. Run focused suites, then the complete test suite, then a live/cached multi-game scanner audit. Do not mark Phase 20 complete or make tactics default if the real promotion gate fails.</action>
  <verify>Run `pytest tests/unit/engines/test_wc_tactical_calibration.py tests/unit/engines/test_wc_model.py tests/unit/scripts/test_wc_scanner.py -q`, then `pytest -q`, then the cached scanner audit documented by the repository workflow.</verify>
  <acceptance>Users can see the evidence state for every probability, all regressions pass, and unvalidated tactics cannot silently reach scanner output.</acceptance>
</task>

## Verification

- Artifact validation and every market gate combination are covered.
- Failed/fallback outputs match no-tactics probabilities exactly.
- Focused and full test suites pass.
- A real scanner audit records artifact identity and per-market status.

## Output

A production-safe tactical calibration path that activates only where the measured out-of-sample evidence supports it.
