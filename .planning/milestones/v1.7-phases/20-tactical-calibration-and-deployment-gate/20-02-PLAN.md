# Plan 20-02: Regularized Residual Training and Evaluation

## Objective

Estimate whether tactical components add probability information beyond the existing baseline, using chronological model selection and an untouched final holdout.

## Tasks

<task type="auto">
  <name>Task 1: Implement bounded residual estimators</name>
  <files>alpha/engines/sports/wc_tactical_calibration.py, tests/unit/engines/test_wc_tactical_calibration.py</files>
  <action>Implement an outcome residual estimator that adjusts baseline matchup strength and a goal residual estimator that adjusts home/away log goal rates. Use the seven named tactical components, standardized from development data only, with strong L2 shrinkage. Preserve fixed baseline offsets and existing Elo/multiplier caps. Fit scoreline effects coherently so totals and BTTS are derived rather than independently nudged. Add a baseline-only recalibration control to distinguish tactical signal from confidence correction.</action>
  <verify>Run `pytest tests/unit/engines/test_wc_tactical_calibration.py -q`; synthetic tests recover a known weak effect, shrink noise toward zero, preserve probability sums, and never exceed caps.</verify>
  <acceptance>The learned layer modifies only residual tactical influence and cannot overwhelm or silently replace the baseline model.</acceptance>
</task>

<task type="auto">
  <name>Task 2: Select regularization chronologically</name>
  <files>scripts/train_wc_tactical_model.py, alpha/engines/sports/wc_tactical_calibration.py, tests/unit/engines/test_wc_tactical_calibration.py</files>
  <action>Use expanding-window folds ordered by kickoff to select regularization from a fixed grid. Fit scalers inside each fold. Optimize outcome log loss for the outcome residual and scoreline negative log likelihood for the goal residual, while reporting Brier score as a co-primary evaluation measure. Reject random CV and assert that each validation timestamp is later than every training timestamp. Refit on all development rows only after selection.</action>
  <verify>Tests inspect fold boundaries, scaler fit ranges, deterministic seeds, and verify that changing a holdout label cannot change selected weights.</verify>
  <acceptance>Hyperparameters and weights are selected without temporal or holdout leakage and are reproducible.</acceptance>
</task>

<task type="auto">
  <name>Task 3: Evaluate against all controls with uncertainty</name>
  <files>scripts/validate_wc_tactics.py, scripts/train_wc_tactical_model.py, tests/unit/engines/test_validate_wc_tactics.py</files>
  <action>Lock weights and thresholds using development plus the 50-match chronological validation set, then evaluate no tactics, v1.6 fixed weights, baseline-only recalibration, and learned tactics once on the sealed 30+ match World Cup audit. For each market compute Brier/log-loss deltas with 10,000 deterministic paired match bootstrap replicates, two-sided 95% intervals, and Holm correction across 1X2/totals/BTTS. Promotion requires at least 0.002 absolute improvement in both metrics against both no tactics and baseline-only recalibration, with every corrected upper confidence bound below zero. Report accuracy, calibration slope/intercept, reliability bins, maximum adjustment, and subgroups second. Never retune after audit results.</action>
  <verify>Run focused tests with fixtures covering pass, mixed-market pass, insufficient sample, and regression. Run the real cached evaluation and emit a Markdown/JSON report.</verify>
  <acceptance>Each market has an evidence-backed pass/fail reason, and no model passes merely because its raw accuracy crossed a threshold.</acceptance>
</task>

- Real evaluation compares all four variants and records uncertainty and per-market gates.

Learned candidate weights plus a complete evaluation report; no runtime activation occurs in this plan.
