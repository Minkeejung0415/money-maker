From alpha/data/ingestion/soccer_stats.py (caching pattern to reuse exactly):

```python
_CACHE_DIR = Path("data/.soccer_cache")

def _cache_path(key: str) -> Path:
    _CACHE_DIR.mkdir(parents=True, exist_ok=True)
    return _CACHE_DIR / f"{key}_{date.today()}.pkl"

def _load_cache(key: str) -> Any | None:
    path = _cache_path(key)
    if path.exists():
        try:
            with open(path, "rb") as f:
                return pickle.load(f)
        except Exception:
            pass
    return None

def _save_cache(key: str, data: Any) -> None:
    try:
        with open(_cache_path(key), "wb") as f:
            pickle.dump(data, f)
    except Exception as exc:
        logger.debug("Cache write failed: %s", exc)
```

From alpha/engines/sports/mlb_training.py (days-rest pattern to mirror):

```python
def _days_rest(last_date_str: str, match_date_str: str) -> int:
    # min=0, max=7, default=3 when no prior game
    delta = date.fromisoformat(match_date_str) - date.fromisoformat(last_date_str)
    return max(0, min(7, delta.days - 1))
```

football-data.org match resource fields (from API docs + research):
- `match["homeTeam"]["id"]` — numeric int (e.g. 57 = Arsenal)

- `match["score"]["fullTime"]["home"]` — int goals (can be None on late update)
- `match["score"]["fullTime"]["away"]` — int goals

    Internal helper _compute_form(team_id: int, matches: list[dict], n: int = 5) -> dict:
    - Filter to matches where score.fullTime.home is not None AND score.winner is not None.

    - Per match: determine is_home = match["homeTeam"]["id"] == team_id; compute gf/ga; classify W/D/L using score.winner; accumulate points (W=3, D=1, L=0).
    - Return dict: team_id, games (count of recent), form_points, form_goal_diff (gf_total - ga_total), goals_for, goals_against, wdl (list, oldest-to-newest).

    - Cache key: f"form_{team_id}"
    - On cache hit: return cached dict.
    - On miss: instantiate FootballDataClient(), call fetch_team_matches(team_id, status="FINISHED", limit=max(n*2, 10)), call _compute_form(team_id, raw, n), cache result, return it.

    Public function fetch_h2h(home_id: int, away_id: int, n: int = 5) -> dict:
    - Cache key: f"h2h_{home_id}_{away_id}"
    - On miss: fetch_team_matches(home_id, status="FINISHED", limit=50).
    - Filter: keep matches where (homeTeam.id==home_id AND awayTeam.id==away_id) OR (homeTeam.id==away_id AND awayTeam.id==home_id). Take last n.

    - Return dict: home_id, away_id, meetings, h2h_home_wins, h2h_draws, h2h_away_wins, h2h_home_win_rate.

    - Return integer.
