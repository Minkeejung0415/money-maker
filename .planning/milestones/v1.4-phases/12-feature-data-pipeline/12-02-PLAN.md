Club Elo API (verified from soccerdata/clubelo.py source):
- Base URL: `http://api.clubelo.com`    (HTTP, not HTTPS — intermittent 503 observed)
- Endpoint: `GET http://api.clubelo.com/YYYY-MM-DD`
- Response: CSV text with columns: Rank, Club, Country, Level, Elo, From, To
- Parse with: `pd.read_csv(io.StringIO(resp.text))`

Club name mapping note (from research):
- clubelo.com uses abbreviated names (e.g. "Man City", "Man United")
- _CLUB_ALIASES dict maps these to full names or football-data.org names
- Alias lookup goes: get_club_elo_rating(club, ratings) -> canonical = _CLUB_ALIASES.get(club, club) -> look up in ratings

soccerdata.FBref (verified from soccerdata 1.8.8 in venv):
- League key for EPL: "ENG-Premier League"
- Season format: seasons=2024 means 2024-25 season
- Instantiation: soccerdata.FBref(leagues="ENG-Premier League", seasons=2024)
- read_team_season_stats(stat_type="passing_types") — returns DataFrame; columns are MultiIndex
- read_team_season_stats(stat_type="misc") — returns DataFrame; contains aerial duels
- CRITICAL: Run df.columns.to_list() in Wave 0 discovery before hardcoding any column paths
- soccerdata caches FBref HTML to ~/soccerdata/data/FBref/ — this is separate from data/.soccer_cache/

      _ELO_FALLBACK = 1500.0

    Alias dict _CLUB_ALIASES (map clubelo.com short names to football-data.org/common names):
      "Man City": "Manchester City"
      "Man United": "Manchester United"
      "Wolves": "Wolverhampton Wanderers"
      "Spurs": "Tottenham Hotspur"
      "Brighton": "Brighton & Hove Albion"
      "Newcastle": "Newcastle United"
      "West Ham": "West Ham United"
      "Nottm Forest": "Nottingham Forest"
      "Leicester": "Leicester City"
      (Add additional aliases as discovered — the dict is the extension point)

    Internal _cache_file(date_str: str) -> Path:
      Returns _CACHE_DIR / f"club_elo_{date_str}.csv"

    Internal _find_stale_cache() -> tuple[Path, int] | None:
      Scan _CACHE_DIR for files matching "club_elo_*.csv". For each, parse date from filename.
      Return (path, age_days) for the most recent one if age_days <= _MAX_STALE_DAYS, else None.

    Internal _parse_csv_to_dict(csv_text: str) -> dict[str, float]:
      df = pd.read_csv(io.StringIO(csv_text))
      Return {row["Club"]: float(row["Elo"]) for _, row in df.iterrows()}
      (handle missing Elo column with empty dict; log warning)

    Public load_club_elo_ratings(date_str: str | None = None) -> dict[str, float]:
      date_str = date_str or date.today().isoformat()
      cache_file = _cache_file(date_str)
      _CACHE_DIR.mkdir(parents=True, exist_ok=True)

      If cache_file.exists(): read CSV text, return _parse_csv_to_dict(text).

      Try: resp = requests.get(f"{_CLUB_ELO_API}/{date_str}", timeout=10); resp.raise_for_status()
           cache_file.write_text(resp.text, encoding="utf-8")
           return _parse_csv_to_dict(resp.text)
      Except Exception as exc:
           logger.warning("clubelo.com fetch failed: %s", exc)
           stale = _find_stale_cache()
           if stale is not None:
               path, age = stale
               logger.warning("Using stale Club Elo cache (%d days old): %s", age, path)
               return _parse_csv_to_dict(path.read_text(encoding="utf-8"))
           raise RuntimeError(f"Club Elo unavailable and no cache found: {exc}") from exc

    Public get_club_elo_rating(club: str, ratings: dict[str, float]) -> float:
      canonical = _CLUB_ALIASES.get(club, club)
      if canonical not in ratings:
          logger.warning("No Club Elo rating for '%s' — using fallback %.0f", club, _ELO_FALLBACK)
          return _ELO_FALLBACK
      return ratings[canonical]

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| club_elo.py -> http://api.clubelo.com | Plaintext HTTP (not HTTPS); response is CSV text parsed by pandas |
| soccer_fbref.py -> soccerdata.FBref | Third-party library that scrapes FBref HTML; 403/bot-detection risk |
| club_elo cache key -> filesystem | date_str used in filename; must be validated to prevent path traversal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04 | Information Disclosure | club_elo.py HTTP (not HTTPS) | accept | clubelo.com does not serve over HTTPS; data is public Elo ratings with no PII; low-value interception target |
| T-12-05 | Tampering | `_cache_file(date_str)` path construction | mitigate | Validate date_str matches YYYY-MM-DD format before use in filename: `date.fromisoformat(date_str)` raises ValueError on malformed input; wrap in try/except |
| T-12-06 | Denial of Service | clubelo.com 503 blocking scanner startup | mitigate | Stale cache fallback with max_age_days=2 prevents total failure; RuntimeError raised only when no cache exists at all |
| T-12-07 | Tampering | soccerdata FBref scraping injecting malformed data | accept | FBref HTML is a trusted source (fbref.com); soccerdata is a published library with known users; DataFrame parsing validates types implicitly |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan — soccerdata, requests, pandas are pre-existing and previously audited |
</threat_model>
