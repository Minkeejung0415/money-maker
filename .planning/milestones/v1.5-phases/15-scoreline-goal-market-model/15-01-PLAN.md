# Phase 15 Plan 01: Scoreline Goal-Market Model

## Objective

Create a deterministic World Cup scoreline model that uses historical attack and defense priors, calibrates its 1X2 cells to `WCMatchModel` output, and evaluates correlated goal-market combinations exactly.

## Tasks

1. Add unit tests for bounded goal rates, probability coherence, Elo marginal calibration, and correlated joint probability.
2. Implement a standalone scoreline distribution module with neutral fallbacks and contradiction validation.
3. Expose the distribution and derived market probabilities on enriched WC game dictionaries.
4. Run focused tests and the full regression suite.

## Verification

- 1X2 scoreline marginals match model output within `1e-4`.
- Over/under and BTTS pairs sum to one.
- Joint probability differs from naive multiplication for correlated legs.
- Contradictory legs raise `ValueError`.
