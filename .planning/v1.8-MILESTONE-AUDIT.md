## Audit Notes

- The v1.8 runtime is intentionally conservative. It scores player-aware artifacts only when the artifact is validated and the game carries required precomputed player-aware features.
- If v1.8 cannot score a game, runtime falls back to a validated v1.3 bundle when available, then to labeled market-implied output.
- Uncertain player-aware predictions are displayed but marked low confidence and excluded from moneyline parlay construction.
- A full live player-aware feature refresh/build job remains a future enhancement; the runtime contract is now ready for such an artifact.
