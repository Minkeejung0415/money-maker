# Phase 16 Plan 01: True SGP Builder and Scanner

## Objective

Normalize real World Cup market prices, create ranked 2-3 leg same-match combinations from the Phase 15 distribution, and add an explicit scanner mode without altering classic parlays.

## Tasks

1. Add tests and a backward-compatible market-odds parser for override data.
2. Extend `WCSGPBuilder` with a true-SGP method using exact joint probabilities and stage gates.
3. Add `--mode sgp` routing and concise output to `wc_scanner.py`.
4. Run focused scanner/builder tests and the full regression suite.

## Verification

- Only legs carrying actual prices are considered.
- Every combination contains one event ID and 2-3 compatible legs.
- Knockout combinations contain no 90-minute 1X2 leg.
- Existing `build()` and `--mode parlay` contracts pass unchanged.
