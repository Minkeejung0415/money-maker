<objective>
Add a leakage-safe MLB player-aware feature builder that consumes Phase 21 canonical game/player-slot rows and produces one modeling row per game with starter, lineup, bullpen, absence, missingness, confidence, and target fields.
</objective>

<must_haves>
- Keep `alpha/engines/sports/mlb_training.py` and v1.3 `FEATURE_NAMES` unchanged.
- Add new code in `alpha/engines/sports/mlb_player_features.py`.
- Add deterministic unit tests in `tests/unit/engines/test_mlb_player_features.py`.
- Default all history lookups to strictly before the target game date/game key.
- Same-day doubleheaders must not leak by default; between-games leakage is allowed only through an explicit `allow_between_games=True` parameter.
- Do not add model training, LightGBM, calibration, artifacts, or runtime scanner changes in this phase.
</must_haves>

<tasks>

1. **Create player-aware feature module**
   - Files: `alpha/engines/sports/mlb_player_features.py`
   - Action: Add pure helper functions and the public `build_player_aware_game_rows(...)` contract.
   - Verify: Module imports without touching v1.3 baseline code.
   - Acceptance criteria:
     - Public row builder returns sorted list of dict rows.
     - Rows include `game_id`, `game_date`, teams, `home_win` when available, and player-aware feature columns.

2. **Implement starter features**
   - Files: `alpha/engines/sports/mlb_player_features.py`
   - Action: Compute shifted starter quality, workload, rest, and missing flags for home/away starters plus differentials.
   - Verify: Tests prove target-game pitcher logs do not affect target-game starter features.
   - Acceptance criteria:
     - `sp_quality_diff`, `home_sp_quality`, `away_sp_quality`, rest/workload fields, and missing flags are emitted.

3. **Implement lineup features**
   - Files: `alpha/engines/sports/mlb_player_features.py`
   - Action: Aggregate Phase 21 player slots and shifted batter value rows into lineup strength, top-order strength, handedness/platoon proxy, missing count, and confirmed share.
   - Verify: Tests cover projected vs confirmed lineups and missing player values.
   - Acceptance criteria:
     - `lineup_strength_diff`, side-specific lineup values, missing counts, and `lineup_confirmed_share` fields are emitted.

4. **Implement bullpen and absence features**
   - Files: `alpha/engines/sports/mlb_player_features.py`
   - Action: Add shifted recent-relief workload/quality summaries and structured absence deltas from absence rows.
   - Verify: Tests prove same-day relief rows do not leak into target-game bullpen features by default.
   - Acceptance criteria:
     - Bullpen workload/quality features and `absence_value_diff` are emitted.
     - Absence rows are keyed by game/team/player and never use crude team average/HR penalties.

5. **Implement leakage and doubleheader tests**
   - Files: `tests/unit/engines/test_mlb_player_features.py`
   - Action: Add focused in-memory tests for starter, lineup, bullpen, absence, and doubleheader handling.
   - Verify: Run focused tests plus Phase 21 and v1.3 regression tests.
   - Acceptance criteria:
     - Default doubleheader behavior excludes same-day game-one outcomes from game two features.
     - `allow_between_games=True` explicitly changes the behavior for prior same-day games.

</tasks>
