# Phase 25 Plan: Evaluation Framework

## Goal

Build the chronological backtest infrastructure that every subsequent WC model phase (26–32) will run against. Delivers: embedded historical match dataset, multiclass metrics (Brier/log-loss/accuracy/A-grade), isotonic calibration module, and promotion gate function.

## Implementation Steps

### Task 1: Historical match data module
- Create `data/wc_historical_matches.py` with embedded WC 2018 group stage (48 matches) + WC 2022 group stage (48 matches) as a Python list of dicts
- Each record includes: `year`, `stage`, `group`, `home_team`, `away_team`, `home_score`, `away_score`, `outcome` (W/D/L), `league="wc"`, and `home_elo_override`/`away_elo_override` for the 11 teams not in current `wc_priors.json`
- Knockout rounds (16+16 = 32 matches): add with `outcome` encoded as AET/penalty winner (never "D" for knockout), `stage` in `KNOCKOUT_STAGES` set
- Elo overrides for missing teams: Russia=1685, Peru=1810, Denmark=1835, Iceland=1767, Nigeria=1655, Costa Rica=1698, Serbia=1720, Korea Republic=1770, Poland=1780, Wales=1799, Cameroon=1625
- Export: `WC_HISTORICAL: list[dict]` and `get_matches(year=None, stage=None) -> list[dict]` filter helper

### Task 2: Calibration and metrics module
- Create `alpha/engines/sports/wc_calibration.py`
- `multiclass_brier(y_true_labels: list[int], y_pred_probs: list[list[float]]) -> float` — Formula A: `np.mean(np.sum((y_pred - y_true_onehot)**2, axis=1))`; label_to_int = {"W":0,"D":1,"L":2}
- `compute_a_grade(y_true_labels, y_pred_probs) -> dict` — returns `a_grade_rate`, `a_grade_count`, `a_grade_eligible`, `a_grade_coverage`
- `log_calibration_summary(y_true_labels, y_pred_probs, class_names) -> None` — text-only calibration curve via `sklearn.calibration.calibration_curve` (no matplotlib)
- `WCIsotonicCalibrator` class — per-class binary IR with `out_of_bounds="clip"`, `fit(probs, outcomes)` on val fold only, `predict(probs)` renormalizes rows to sum to 1
- `promotion_gate(baseline: dict, candidate: dict, min_delta=0.001) -> tuple[bool, str]` — PASS requires both `brier_delta > min_delta` AND `log_loss_delta > min_delta`; identical models always FAIL
- `evaluate_model(model, matches, calibrator=None) -> dict` — runs `model.predict(dict(m))` (copy!) for each match, collects predictions, returns metrics dict with `brier`, `log_loss`, `accuracy`, `a_grade`, `n_samples`

### Task 3: Backtest runner script
- Create `scripts/wc_eval.py`
- Load `WC_HISTORICAL` from `data.wc_historical_matches`; NEVER import from wc_scanner, live fetchers, or football_data_client
- Chronological split: `train_2018 = get_matches(year=2018)`, `test_2022 = get_matches(year=2022)`
- Fit `WCIsotonicCalibrator` on `train_2018` only (EVAL-03)
- Instantiate `WCMatchModel()`; run `evaluate_model()` on `test_2022` with and without calibration
- Print results table: Brier, log loss, accuracy, A-grade rate/coverage for both uncalibrated and calibrated
- Print promotion gate result comparing uncalibrated vs calibrated (sanity check — calibration should improve Brier)
- `--help` flag; exits cleanly; no side-effects on any data files

### Task 4: Tests — calibration module
- Create `tests/unit/engines/test_wc_calibration.py`
- `test_multiclass_brier_perfect_prediction` — all-correct predictions → Brier = 0.0
- `test_multiclass_brier_worst_prediction` — all wrong with prob=1.0 → Brier = 2.0
- `test_multiclass_brier_formula_a_not_b` — verify result is ~3× a per-class binary brier (catches formula confusion)
- `test_a_grade_metric_basic` — two eligible-correct, one eligible-wrong → rate=0.5, eligible=2
- `test_a_grade_no_eligible` — all top probs < 0.65 → a_grade_rate=0.0, a_grade_eligible=0
- `test_calibrator_fit_predict_shape` — fit on 10 samples, predict 5 → output shape (5,3), rows sum to 1.0
- `test_calibrator_probs_sum_to_one` — after predict(), every row within 1e-6 of 1.0
- `test_promotion_gate_identical_fail` — same dict as baseline and candidate → returns (False, ...)
- `test_promotion_gate_real_improvement` — candidate brier 0.05 and log_loss 0.05 lower → returns (True, ...)
- `test_promotion_gate_one_metric_fails` — brier improves but log_loss regresses → returns (False, ...)
- `test_promotion_gate_subthreshold` — both deltas = 0.0005 (< min_delta) → returns (False, ...)

### Task 5: Tests — backtest eval
- Create `tests/unit/engines/test_wc_eval.py`
- `test_get_matches_year_filter` — `get_matches(year=2018)` returns only 2018 records
- `test_get_matches_stage_filter` — `get_matches(stage="GROUP_STAGE")` returns no knockout records
- `test_evaluate_model_copies_game_dict` — after evaluate_model(), original match dicts are unmodified (no mutation leakage)
- `test_evaluate_model_returns_expected_keys` — result dict has `brier`, `log_loss`, `accuracy`, `a_grade`, `n_samples`
- `test_elo_override_used` — match with `home_elo_override=2000` against away_elo=1500 → win_prob > 0.80 (confirms override was used, not fallback)
- `test_no_draw_in_knockout_labels` — all knockout records in `WC_HISTORICAL` have outcome in {"W","L"} (no "D")
