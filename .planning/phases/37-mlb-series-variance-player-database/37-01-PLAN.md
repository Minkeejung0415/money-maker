<objective>

<tasks>

1. Patch explicit date propagation.
   - File: `scripts/mlb_scanner.py`
   - Action: pass `game_date=args.date` into `build_live_player_features(...)`.
   - Acceptance criteria:
     - `--date YYYY-MM-DD` controls both schedule fetch and probable-pitcher/player feature lookup.
     - Default behavior remains unchanged when `--date` is omitted.

2. Add scanner regression coverage.
   - File: `tests/unit/test_mlb_scanner.py`
   - Action: test that `main()` calls `fetch_today_games(args.date)` and `build_live_player_features(..., game_date=args.date, ...)`.
   - Acceptance criteria:
     - Test fails on the current bug and passes after the patch.
     - Existing `--individual-only` tests still pass.

3. Add same-series feature variance coverage.
   - File: `tests/unit/test_mlb_live_player_features.py`
   - Action: add a focused test with two games from the same matchup/date but different event IDs and starter mappings, or provider-controlled pitcher quality, proving feature outputs can differ by game when inputs differ.
   - Acceptance criteria:
     - Test demonstrates the feature layer does not force identical probabilities solely because team names repeat.
     - Missing starter/team fallback still sets uncertainty flags as before.

4. Improve scanner output diagnostics if needed.
   - File: `scripts/mlb_scanner.py`
   - Action: ensure individual output includes the existing `sp_quality_diff` context whenever available, and do not hide suppression reasons.
   - Acceptance criteria:
     - A repeated matchup can be inspected from output and show whether starter/player context differs.

</tasks>
