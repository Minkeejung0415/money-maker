    MODULE DOCSTRING: "Build WC 2026 priors: Elo ratings + StatsBomb team stats. ONE-TIME OFFLINE SCRIPT — runtime ~2-5 minutes. Outputs: data/wc_priors.json, data/.wc_cache/wc_stats.pkl. Usage: ./venv/Scripts/python.exe scripts/build_wc_priors.py"

    IMPORTS: `from __future__ import annotations`, `import json`, `import logging`, `import pickle`, `import time`, `from pathlib import Path`, `import requests`, `import pandas as pd`. Then `from statsbombpy import sb`. Logger setup: `logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s")` and `logger = logging.getLogger(__name__)`.

    CONSTANTS:
    - `WC_SEASONS = [{"competition_id": 43, "season_id": 3}, {"competition_id": 43, "season_id": 106}]`
    - `WC_CACHE_DIR = Path("data/.wc_cache")`
    - `WC_STATS_CACHE = WC_CACHE_DIR / "wc_stats.pkl"`
    - `WC_PRIORS_PATH = Path("data/wc_priors.json")`
    - `ELO_BASE = "https://www.eloratings.net"`
    - `ELO_FALLBACK = 1500`
    - `ELO_SLEEP = 0.1`

    WC_2026_TEAMS constant: list of 48 team names as they appear on eloratings.net (use the football-data.org name format as the canonical key). Include all 48 teams qualified for WC 2026. Team name → slug by replacing spaces with underscores.

    FUNCTION `_fetch_team_elo(team_name: str) -> int`: builds slug via `team_name.replace(" ", "_")`, GET `{ELO_BASE}/{slug}.tsv` with `headers={"User-Agent": "alpha-terminal/1.1"}` and `timeout=10`. Split response text into rows by splitlines(), split each row by "\t". Take last row. If `len(last_row) > 10`, return `int(float(last_row[10]))`. Validate: if value is outside 1000-2200 range, log warning and return ELO_FALLBACK. Return ELO_FALLBACK on any exception. Always call `time.sleep(ELO_SLEEP)` in a finally block. Log warning on fallback.

    FUNCTION `_fetch_elo_ratings(teams: list[str]) -> dict[str, int]`: iterate teams, print progress `f"\r  [{i+1}/{len(teams)}] {team:<40}"`, call `_fetch_team_elo(team)`, store in ratings dict. Print newline after loop. Return ratings.

    FUNCTION `_fetch_statsbomb_stats() -> dict[str, dict]`: iterate WC_SEASONS, for each call `sb.matches(competition_id=s["competition_id"], season_id=s["season_id"])`. Get match_id list. For each match_id, try `sb.events(match_id=match_id)`, except Exception log warning and continue. Filter to `events["type"] == "Shot"`. For each shot event, accumulate per-team: shots count, xG sum (column "shot_statsbomb_xg"), goals (where "shot_outcome" == "Goal"), opponent xG (shots by opponent team in same match). Track match count per team. After all seasons: compute avg_goals = goals / n_games, avg_xG = xg_for / n_games, avg_shots = shots_count / n_games, defense_score = xg_against / n_games for each team. Log info with n_games_loaded count. Return the stats dict (without "built_at" — added by caller).

    Implementation note for _fetch_statsbomb_stats: The efficient approach is to build two accumulators: `team_offense: dict[str, dict]` (team → {goals, xg, shots, n_games}) and `team_defense: dict[str, float]` (team → opponent_xg_total). For each match: get home_team and away_team from the matches DataFrame row; filter shot events to home shots and away shots; add opponent's xG to each team's defense accumulator.

    FUNCTION `build_wc_priors()`:
    1. Create WC_CACHE_DIR with mkdir(parents=True, exist_ok=True)
    2. Print "=== Fetching Elo ratings from eloratings.net ==="
    3. Call _fetch_elo_ratings(WC_2026_TEAMS), get ratings dict
    4. Write WC_PRIORS_PATH as json.dump(ratings, f, indent=2, ensure_ascii=False)
    5. Log info "Wrote %d team Elo ratings to %s"
    6. Print "\n=== Fetching StatsBomb 2018+2022 WC event data ==="
    7. Call _fetch_statsbomb_stats(), get stats dict
    8. Add `stats["built_at"] = str(pd.Timestamp.now())`
    9. Always overwrite WC_STATS_CACHE (no existence check): open "wb", pickle.dump(stats, f)
    10. Log info "Wrote WC stats to %s (%d teams)"
    11. Print summary: "=== Build complete ===" + list how many teams in each output

    `if __name__ == "__main__": build_wc_priors()`

    WC_2026_TEAMS list (48 teams): Argentina, Australia, Belgium, Brazil, Cameroon, Canada, Chile, Colombia, Costa Rica, Croatia, Ecuador, Egypt, England, France, Germany, Ghana, Honduras, Iran, Italy, Japan, Jamaica, Kenya, Korea Republic, Mali, Mexico, Morocco, Netherlands, New Zealand, Nigeria, Panama, Paraguay, Peru, Poland, Portugal, Saudi Arabia, Senegal, Serbia, Slovenia, South Africa, Spain, Switzerland, Trinidad and Tobago, Tunisia, Turkey, Ukraine, United States, Uruguay. (Note: exact WC 2026 qualifications; executor should verify final 48 from an authoritative source and update this list.)

    Note on team name slug edge cases: names with apostrophes or special chars should be sanitized. Simple approach: replace spaces with underscores, drop apostrophes, replace accented chars with ASCII equivalents if needed. Log when a slug does not return valid data.
