# Phase 27 Plan: Projected XI Layer

## Goal

Build the `LineupProjector` class that estimates starter probabilities, aggregates line scores by SUM (not mean), computes replacement-adjusted absence impact, and produces lineup uncertainty variance bands. API is designed so Phase 30 can plug in real player data.

## Implementation Steps

### Task 1: `alpha/engines/sports/wc_lineup.py`

"""
LineupProjector — starter probability estimation and line score aggregation.

Design:
  - Input: squad dict {player_name: PlayerInfo}
  - Output: LineupFeatures dataclass
  - Line scores use SUM (not mean) so 11 players > 10 players
  - Absence impact = player_value - replacement_value (in same role)
  - Uncertainty band from std dev of p_start across squad
  - Continuity modifier for back-line/GK changes vs reference lineup
"""

**`PlayerInfo` TypedDict or dataclass:**
```python
@dataclass
class PlayerInfo:
    role: str          # "GK","CB","LB","RB","DM","CM","LW","RW","ST","SS"
    p_start: float     # starter probability [0.0, 1.0]
    value: float       # player quality score (0–100 scale)
    replacement_value: float  # best available replacement's value in same role
```

**Line groupings:**
```python
LINE_GROUPS = {
    "GK":       {"GK"},
    "Back":     {"CB", "LB", "RB"},
    "Midfield": {"DM", "CM"},
    "Front":    {"LW", "RW", "ST", "SS"},
}
```

**`LineupFeatures` dataclass:**
```python
@dataclass
class LineupFeatures:
    gk_score: float           # sum of (value * p_start) for GK line
    back_score: float         # sum for Back line
    midfield_score: float     # sum for Midfield line
    front_score: float        # sum for Front line
    total_score: float        # gk + back + midfield + front
    expected_starters: float  # sum of all p_start values (should be ~11)
    absence_impacts: dict[str, float]  # player_name -> absence delta (positive = loss)
    uncertainty_band: float   # std dev of p_start values; high = more certain XI
    continuity_modifier: float  # 0.0 if unchanged, -0.05 per back/GK change
    lineup_confidence: str    # "HIGH" if uncertainty_band > 0.35 else "LOW"
```

**`LineupProjector` class:**
```python
class LineupProjector:
    def __init__(self, reference_lineup: dict[str, str] | None = None) -> None:
        """
        reference_lineup: {player_name: role} — the known lineup from last match.
        Used to compute continuity modifier. None = no continuity check.
        """
        self._reference = reference_lineup or {}

    def project(self, squad: dict[str, PlayerInfo]) -> LineupFeatures:
        """
        Compute lineup features from squad probabilities.

        Line score = sum(player.value * player.p_start) for players in line.
        Absence impact = player.value - player.replacement_value (always >= 0).
        Uncertainty = std dev of p_start values.
        Continuity = -0.05 for each GK or CB not in reference lineup (if reference set).
        """
        # 1. Line scores (SUM not mean)
        # 2. expected_starters = sum of all p_start
        # 3. Absence impacts per player
        # 4. Uncertainty band = std dev of p_start
        # 5. Continuity: compare GK/CB players (p_start > 0.5) vs reference
        # 6. lineup_confidence = "HIGH" if std_dev > 0.35 else "LOW"
        # (high std dev means some players clearly starting, others clearly not — more certain XI)
```

### Task 2: Tests — `tests/unit/engines/test_wc_lineup.py`

- `test_line_scores_sum_not_mean` — squad with 3 CB at value=80 and p_start=1.0 → back_score=240, not 80

- `test_expected_starters_approx_eleven` — default mock squad → expected_starters ≈ 11.0 ±0.5
- `test_absence_impact_key_player` — player value=90, replacement=60 → absence_impact=30

- `test_uncertainty_high_when_probs_bimodal` — mix of p_start=1.0 and p_start=0.0 → high std dev
