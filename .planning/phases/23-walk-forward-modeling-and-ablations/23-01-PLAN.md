# Phase 23 Plan: Walk-Forward Modeling and Ablations

## Goal

Train and compare MLB moneyline model candidates through leakage-safe walk-forward ablations, while preserving the v1.3 baseline as a reproducible scorecard.

## Implementation Steps

1. Add `alpha/engines/sports/mlb_player_modeling.py`.
   - Define baseline and player-aware feature-set constants.
   - Build train/calibration/test walk-forward splits.
   - Expose model factories for logistic, HistGradientBoosting, and optional LightGBM.

2. Implement scoring and calibration helpers.
   - Fit models on train folds only.
   - Fit a sigmoid calibrator on later calibration folds.
   - Score only later test folds with Brier score, log loss, accuracy, and reliability buckets.
   - Fall back to a prior-probability model when tiny folds lack both classes.

3. Implement ablation runner and artifact metadata.
   - Report all requested feature sets side by side.
   - Aggregate fold metrics per model and feature set.
   - Select a promotable result only when it improves over the v1.3 baseline on Brier score.
   - Build serializable metadata with schema version, feature names, split dates, source fingerprints, metrics, and gates.

4. Add focused unit tests.
   - Feature-set contract includes baseline and all player-aware ablations.
   - Splits are chronological train < calibration < test.
   - Ablation report includes metrics and calibration buckets.
   - LightGBM is optional.
   - Artifact metadata contains the Phase 24 gating fields.
