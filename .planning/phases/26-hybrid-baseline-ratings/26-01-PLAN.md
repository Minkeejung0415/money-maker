# Phase 26 Plan: Hybrid Baseline Ratings

## Goal

Replace the pure Elo-logistic backbone with a hybrid baseline that computes a composite effective Elo per team by combining: sequential Elo-like updates from historical matches, xG attack/defense EWMA states, FIFA SUM ranking feature, host-country flag, and confederation interaction. Expose via `WCTeamRatings` class. Use injection pattern (elo_override) to keep wc_model.py and wc_scanner.py unchanged.

    ) -> None:
        ...

    def get_features(self, home_team: str, away_team: str) -> dict:
        """
        Return hybrid feature dict for a matchup:
          elo            (int)   — home sequential Elo
          elo_away       (int)   — away sequential Elo
          xg_attack      (float) — home xG attack EWMA
          xg_defense     (float) — home xG defense EWMA (lower=better defense)
          xg_attack_away (float)
          xg_defense_away(float)
          fifa_sum       (int)   — home_rank + away_rank (lower=better)
          host_flag      (int)   — 1 if home team is 2026 host (US/Mexico/Canada)
          confederation_interaction (int) — 1 if teams from different confederations
          composite_home_elo (float) — effective Elo for hybrid model
          composite_away_elo (float)
        """

Sequential Elo update logic (BASELINE-01, leakage-free):
- Initialize from `data/wc_priors.json` as starting ratings
- Replay `WC_HISTORICAL` sorted by (year, stage_order) in ascending order
- K=30 for all WC matches (WC literature standard)
- Expected score: `E = 1 / (1 + 10^(-(elo_home - elo_away)/400))`
- Score: W=1.0, D=0.5, L=0.0 (home perspective)
- Update: `elo_home += K * (score - E_home)`, `elo_away += K * (score - E_away)`
- Note: this updates 2018 teams' ratings sequentially through 2022, so by the time `wc_eval.py` tests on 2022, the Elo reflects 2018 form (correct — 2022 Elo was unknown at 2018 kickoff, but we test on 2022 as if 2018 informed 2022 state)

xG EWMA states (BASELINE-02):
- Seed from `.wc_cache/wc_stats.pkl` per-team averages: `xg_attack = avg_xG`, `xg_defense = defense_score`
- For teams not in stats cache: fallback to global average (1.2 xG attack, 1.2 xG defense)
- EWMA alpha = 1 - 0.5^(1/xg_half_life); update after each match replay
- `xg_attack_new = alpha * match_xg_for + (1-alpha) * xg_attack_old`
- Use `home_score` as proxy for xG when actual per-match xG unavailable (acceptable approximation for initialization)

Composite Elo calculation (for injection into WCMatchModel):
- xG adjustment: `xg_adj = 200 * log10((xg_attack/xg_defense_away) / (xg_attack_away/xg_defense))` capped ±40
- FIFA adjustment: `fifa_adj = -0.05 * (home_rank - away_rank)` capped ±20
- Host adjustment: `host_adj = +50` if home team is WC 2026 host (US, Mexico, Canada), else 0
- Confederation adjustment: `conf_adj = +10` if same confederation, `-10` if cross-confederation (neutral venue default)
- `composite_home_elo = sequential_elo_home + xg_adj + fifa_adj + host_adj + conf_adj`
- `composite_away_elo = sequential_elo_away` (adjustments are from home-team perspective)

### Task 3: Hybrid model — `alpha/engines/sports/wc_hybrid_model.py`

```python
class WCHybridModel:
    """
    Wraps WCMatchModel with hybrid composite Elo injection.
    Uses WCTeamRatings to compute composite Elo, injects as
    home_elo_override/away_elo_override, then delegates to WCMatchModel.predict().

    wc_scanner.py is NOT modified — scanner keeps using WCMatchModel directly.
    """

    def __init__(self, k_factor=30.0, xg_half_life=5, min_edge=0.04) -> None:
        self._ratings = WCTeamRatings(k_factor=k_factor, xg_half_life=xg_half_life)
        self._base_model = WCMatchModel(min_edge=min_edge)

    def predict(self, game: dict) -> dict:
        """Inject composite Elo overrides then delegate to WCMatchModel.predict()."""
        features = self._ratings.get_features(game["home_team"], game["away_team"])
        g = dict(game)
        g["home_elo_override"] = int(features["composite_home_elo"])
        g["away_elo_override"] = int(features["composite_away_elo"])
        g["model_name"] = "wc_hybrid_baseline"
        return self._base_model.predict(g)
```
